Zakres specyfikacji:

Zarządzanie endpointami
- Dodawanie adresu API.
- Wybór metody HTTP (GET, POST, PUT, DELETE).
- Konfiguracja oczekiwanego kodu odpowiedzi.
- Ustawienie częstotliwości sprawdzania.
Monitoring
- Wysyłanie żądań.
- Odczytywanie odpowiedzi HTTP.
- Mierzenie czasu odpowiedzi.
- Wykrywanie timeoutów i błędów połączenia.
Historia i diagnostyka
- Zapisywanie wyników.
- Historia kodów HTTP.
- Historia czasów odpowiedzi.
- Informacje o błędach.
- Możliwość porównywania wyników.
Dashboard
- Lista monitorowanych endpointów.
- Aktualny status.
- Statystyki.
- Historia sprawdzeń.
